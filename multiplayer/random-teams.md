# 13. Random Teams in Skirmish and LAN

**Random Teams** appears below **Ring Heroes** on the **Rules** tab. It is off by default. When enabled, the team selectors are disabled and the host assigns occupied player slots to teams 1 and 2 at match start. Human players and AI are included. Empty slots and observers keep their existing state. The teams differ by at most one player.

The rule applies to new tactical matches. Clan games, War of the Ring, and restored lobbies keep their native team rules.

## Menu assets and localization

The reference menu assets already have four instances of the checkbox row in the `MpGameSetup` movie. Skirmish and LAN both import that movie's `MpMapAndSettings` export, so both use the same rows. The engine now supplies four rules to that menu in this order.

| Row name | Native rule ID | Label |
| --- | --- | --- |
| `0` | `0` | Custom Heroes |
| `1` | `2` | Ring Heroes |
| `2` | `9` | Random Teams |
| `3` | `1` | Clan Game, where the native UI shows it |

For a layout with three rows, unpack the setup movie BIG and decode `MpGameSetup.apt` and its matching `.const` with `sage_apt`. Browse the `MpMapAndSettings` export to its Rules panel. In the reference movie the export is sprite `188`, which uses `18`, which uses the row container `10`. In frame zero, reuse character `9` for all four checkbox rows. Rename the former third row to `3`, clone a row as `2`, and place it below `1`. Use unused display depths. In the reference asset the row translations are `(19.85, -13.9)`, `(19.85, 18.5)`, `(19.85, 50.9)`, and `(19.85, 83.9)`, with depths `5`, `1`, `9`, and `13`. Keep the row's existing `AptMpGameRules::InitGadgets` action and the `MpGameRules::NumCheckBoxes` lookup. Re-encode the APT and CONST together and replace those BIG members. The reference build uses the prepared menu layout directly.

## Engine implementation

The tactical checkbox table uses the existing ten-slot rules buffer. The builder adds rule ID 9 with a default of 0 and changes the visible rule count from three to four. LAN clients and the host refresh their team selectors after a rules update.

| Address | Purpose |
| --- | --- |
| `0x00960A41`, `0x00960A71` | Redirect the tactical checkbox list and set its count to four. |
| `0x00960B14` | Resolve the Random Teams label for the tactical menu. |
| `0x00842BCB` | Route team selectors through the native disabled path while the rule is active. |
| `0x008403BB` | Reject a manual team choice before it can modify the roster. |
| `0x00843403` | Treat slots as unassigned during the lobby's team-count check until the host assigns them. |
| `0x00843874` | Assign teams before the native host start call. |
| `0x00846B67` | Refresh the UI after applying a new rules state. |

The host collects the active slots, shuffles them with a local random state seeded from the host clock and match seed, then alternates team IDs 0 and 1 in the shuffled roster. These are displayed as teams 1 and 2. It randomly selects which team gets the extra slot when the player count is odd. The engine's game-logic RNG and match-start roster handoff retain their native behavior.

## Verify in game

1. Open the Rules tab and verify the row order and the default unchecked state. Assign every active slot to the same team, then enable Random Teams. Check that the team controls become disabled and the match can start.
2. Start games with even and odd numbers of players. Check that teams use the labels 1 and 2 and that the size difference is at most one.
3. Add AI and an observer. Verify that AI joins the draw, while the observer stays an observer.
4. Disable the rule and check that manual team assignment works. In a LAN lobby, toggle it on the host and verify that connected clients see the same selector state.

The APT row layout, checkbox state, manual selection guard, and final roster handoff were checked in emulation. Verify a live Windows Skirmish and LAN match with the listed steps.

```c
typedef unsigned int u32;
typedef u32 String;

#define THISCALL __attribute__((thiscall))
#define STDCALL __attribute__((stdcall))
#define AT(type, address) (*(type *)(address))

enum { SLOT_COUNT = 8, RANDOM_TEAMS = 9 };

typedef struct { int id; unsigned char enabled; } CheckRule;
static const CheckRule random_teams_rule = {RANDOM_TEAMS, 0};
const CheckRule *const tactical_rules[] = {
    (const CheckRule *)0xc82528,   /* Custom Heroes */
    (const CheckRule *)0xc82530,   /* Ring Heroes */
    &random_teams_rule,
    (const CheckRule *)0xc82538,   /* Clan Game */
};

typedef char *(THISCALL *SlotGetter)(void *, int);
typedef unsigned char (THISCALL *SlotTest)(void *);
typedef void (THISCALL *GameCallback)(void *);
typedef void (THISCALL *CopyText)(String *, const String *);
typedef const String *(THISCALL *FetchText)(void *, const char *, unsigned char *);
typedef unsigned char (THISCALL *LoadTextTable)(void *, const char *, const char *, unsigned char *);
typedef const String *(THISCALL *FindText)(void *, const char *);
typedef u32 (STDCALL *Clock)(void);

static const char random_teams_key[] = "RULE:RandomTeams";
static u32 language_table[3];
static int language_checked;

int tactical_panel(const char *panel)
{
    return panel && AT(int, panel + 0x7c) == 0;
}

int random_teams_enabled(const char *panel, const char *game)
{
    return tactical_panel(panel) && game && !AT(void *, panel + 0x2b0) &&
        AT(int, game + 0x64) != 1 && AT(int, game + 0x60 + RANDOM_TEAMS * 4) == 1;
}

String *random_team_text(String *out)
{
    void *manager = AT(void *, 0xde4b04);
    *out = 0;
    if (!manager)
        return out;
    unsigned char found = 0;
    const String *text = ((FetchText)0x6e7a63)(manager, random_teams_key, &found);
    if (!found) {
        if (!language_checked) {
            language_checked = 1;
            ((LoadTextTable)0x6e7d9e)(language_table, 0, "lang\\ROTWKRandomTeams.csf", 0);
        }
        if (language_table[0]) {
            const String *translated = ((FindText)0x6e7903)(language_table, random_teams_key);
            if (translated)
                text = translated;
        }
    }
    if (text)
        ((CopyText)0x436a90)(out, text);
    return out;
}

void THISCALL refresh_rules(char *panel)
{
    ((GameCallback)0x84003c)(panel);
    /* A rules update reaches this path both on the host and on LAN clients. */
    if (tactical_panel(panel))
        AT(unsigned char, panel + 0x2b9) = 1;
}

static u32 next_random(u32 *state)
{
    u32 value = *state;
    value ^= value << 13;
    value ^= value >> 17;
    value ^= value << 5;
    return *state = value;
}

void assign_random_teams(char *panel, char *game)
{
    if (!random_teams_enabled(panel, game))
        return;

    char *players[SLOT_COUNT];
    u32 count = 0;
    for (int index = 0; index < SLOT_COUNT; ++index) {
        char *slot = ((SlotGetter)0x800b55)(game, index);
        if (slot && ((SlotTest)0x8009b1)(slot) && !((SlotTest)0x800a1b)(slot))
            players[count++] = slot;
    }
    if (!count)
        return;

    /* Use the host clock and match seed without advancing the game-logic RNG. */
    u32 state = AT(Clock, 0xbd0920)() ^ AT(u32, game + 0x50);
    if (!state)
        state = 0x9e3779b9u;
    for (u32 end = count - 1; end > 0; --end) {
        u32 index = next_random(&state) % (end + 1);
        char *slot = players[end];
        players[end] = players[index];
        players[index] = slot;
    }
    u32 first = next_random(&state) & 1u;
    for (u32 index = 0; index < count; ++index)
        AT(int, players[index] + 0x1c) = (first + index) & 1u;
}
```

```asm
.intel_syntax noprefix
.code32
.text

.global rule_string, lock_team_combo, reject_team_choice, validate_team_count, start_random_teams

rule_string:
    cmp dword ptr [esp+8], 9
    jne .Lstock_label
    push dword ptr [0xde8d78]
    call tactical_panel
    add esp, 4
    test eax, eax
    jnz random_team_text
.Lstock_label:
    push ebp
    mov ebp, esp
    push ecx
    mov eax, [ebp+0xc]
    jmp 0x960b1b

lock_team_combo:
    pushad
    push dword ptr [ebp-0x18]
    push esi
    call random_teams_enabled
    add esp, 8
    test eax, eax
    popad
    jnz 0x842beb          # Use the native disabled path, which also closes the dropdown.
    cmp dword ptr [esi+0x160], 1
    jmp 0x842bd2

reject_team_choice:
    pushad
    push dword ptr [ebp-8]
    push esi
    call random_teams_enabled
    add esp, 8
    test eax, eax
    popad
    jz .Lread_team
    xor eax, eax
    jmp 0x840408          # Return before reading or applying the selected team.
.Lread_team:
    push ebx
    mov ebx, [ebp+8]
    push edi
    lea eax, [ebp-4]
    jmp 0x8403c3

validate_team_count:
    pushad
    push dword ptr [ebp-0x28]
    push esi
    call random_teams_enabled
    add esp, 8
    test eax, eax
    popad
    jnz 0x84341f          # Count this slot as unassigned until the host starts.
    mov eax, [edi+0x1c]
    cmp eax, ebx
    jmp 0x843408

start_random_teams:
    pushfd
    pushad
    push dword ptr [ebp-0x28]
    push esi
    call assign_random_teams
    add esp, 8
    popad
    popfd
    push dword ptr [ebp-0x20]
    mov ecx, [esi+0x58]
    jmp 0x84387a          # Hand the completed roster to the existing host start path.
```

```python
from argparse import ArgumentParser
from hashlib import sha256
from pathlib import Path
from struct import pack
from subprocess import check_output, run
from tempfile import TemporaryDirectory

from sage_patch.utils import allocate_section, apply_byte_patch, call_rel32, file_offset, jmp_rel32

HERE = Path(__file__).resolve().parent
GAME_SHA256 = '1b4c0d8963aedf46e3d939e4057a05e1a55050b7f4e01472320fbd64e90c5112'
HOOKS = (
    (0x960b14, '558bec518b450c', 'rule_string', jmp_rel32),
    (0x842bcb, '83be6001000001', 'lock_team_combo', jmp_rel32),
    (0x8403bb, '538b5d08578d45fc', 'reject_team_choice', jmp_rel32),
    (0x843403, '8b471c3bc3', 'validate_team_count', jmp_rel32),
    (0x843874, 'ff75e08b4e58', 'start_random_teams', jmp_rel32),
    (0x846b67, 'e8d094ffff', 'refresh_rules', call_rel32),
)
LANGUAGE_KEY = 'RULE:RandomTeams'
LANGUAGE_VALUE = 'Random Teams'


def patch_game(base, work):
    assert sha256(base).hexdigest() == GAME_SHA256
    image = bytearray(base)
    module, hooks, elf, raw, linker = (
        work / name for name in ('teams.o', 'hooks.o', 'teams.elf', 'teams.bin', 'teams.ld')
    )
    run(['gcc', '-m32', '-Os', '-std=c11', '-ffreestanding', '-fno-pic', '-fno-pie',
         '-fno-stack-protector', '-fno-asynchronous-unwind-tables', '-fno-unwind-tables',
         '-fno-ident', '-mno-sse', '-mno-mmx', '-Wall', '-Wextra', '-Werror',
         '-c', HERE / 'random_teams.c', '-o', module], check=True)
    run(['as', '--32', HERE / 'random_teams_hooks.s', '-o', hooks], check=True)
    linker.write_text('''
SECTIONS {
    . = PATCH_ADDRESS;
    .patch : { *(.text*) *(.rodata*) *(.data*) *(.bss*) BYTE(0) }
    /DISCARD/ : { *(.note*) *(.comment*) }
}
''')
    symbols = {}

    def payload(address):
        run(['ld', '-m', 'elf_i386', '--no-warn-rwx-segments', '-T', linker,
             '--defsym', f'PATCH_ADDRESS={address:#x}', '-o', elf, module, hooks], check=True)
        run(['objcopy', '-O', 'binary', '-j', '.patch', elf, raw], check=True)
        for line in check_output(['nm', '--defined-only', elf], text=True).splitlines():
            value, _, name = line.split()
            symbols[name] = int(value, 16)
        return raw.read_bytes()

    allocate_section(image, '.rtteam', payload, 0xe0000060)
    for site, stock, name, branch in HOOKS:
        original = bytes.fromhex(stock)
        replacement = branch(site, symbols[name], len(original)) if branch is jmp_rel32 else branch(site, symbols[name])
        apply_byte_patch(image, file_offset(image, site), original, replacement, name)

    # Expand the tactical list using the existing ten-entry rule buffer.
    apply_byte_patch(image, file_offset(image, 0x960a41), pack('<I', 0xdb77c4),
                     pack('<I', symbols['tactical_rules']), 'tactical checkbox list')
    apply_byte_patch(image, file_offset(image, 0x960a71), b'\x03', b'\x04', 'tactical checkbox count')
    return image, symbols


def main():
    parser = ArgumentParser()
    parser.add_argument('input', type=Path)
    parser.add_argument('output', type=Path)
    args = parser.parse_args()
    with TemporaryDirectory() as folder:
        game, _ = patch_game(args.input.read_bytes(), Path(folder))
    key = LANGUAGE_KEY.encode('ascii')
    wide = LANGUAGE_VALUE.encode('utf-16-le')
    language = (
        pack('<4s5I', b' FSC', 3, 1, 1, 0, 0)
        + pack('<4s2I', b' LBL', 1, len(key)) + key
        + pack('<4sI', b' RTS', len(wide) // 2)
        + bytes(byte ^ 0xff for byte in wide)
    )
    files = {
        'game.dat': game,
        'lang/ROTWKRandomTeams.csf': language,
        'localization/ROTWKRandomTeams.str': f'{LANGUAGE_KEY}\r\n"{LANGUAGE_VALUE}"\r\nEND\r\n'.encode('utf-8'),
    }
    for name, data in files.items():
        target = args.output / name
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_bytes(data)


if __name__ == '__main__':
    main()
```
